# 스노우 엔젤 · SNOW ANGEL

크리스마스 시즌 인터랙티브 전시. 관객이 팔과 다리를 저으면 눈 위에 자국이 새겨지고, 완성된 천사가 빛을 머금고 떠오른 뒤 눈에 덮여 처음으로 돌아갑니다.

## 흐름 (1회 약 14~20초, 자동 순환)

1. **눈**: 빈 눈밭 위로 눈이 내립니다.
2. **몸짓**: 지정 위치에 서서 팔을 한두 번 크게 저으면 그만큼 자국이 새겨집니다. 다리 움직임은 진행도에 보너스로 반영됩니다. 최소 6초에서 최대 12초 동안 진행됩니다.
3. **비상**: 완성된 천사가 금빛으로 빛나며 떠오릅니다(4.5초).
4. **덮임**: 눈이 흔적을 덮고 처음으로 돌아갑니다(3.5초).

- 동시에 1~2명이 참여합니다(화면 왼쪽과 오른쪽 자리에서 각 한 명). 작은 배경 인물은 어깨·몸통의 화면상 크기로 제외하고, 잠깐 가려진 참가자의 자리는 1.8초 동안 유지합니다.
- 두 명이 참여하면 각자의 동작이 충분히 쌓여야 조기 완료됩니다. 최대 12초가 지나면 자동으로 다음 장면으로 넘어갑니다.
- 가로형 TV에서는 인식된 사람의 카메라 미리보기와 각자의 진행도가 화면 하단 왼쪽·오른쪽 카드에 표시됩니다. 배경 제거 결과가 있으면 미리보기에 겹쳐 보여주며, 중앙 눈밭에는 몸짓으로 만든 자국이 남습니다.
- 몸통 길이를 측정해 자국을 화면 높이에 맞는 일정한 크기로 그립니다. 관객이 카메라에 가까워지거나 멀어져도 자국 크기가 급격히 변하지 않습니다.
- 영상은 저장하지 않고 브라우저 안에서 실시간으로만 처리합니다.
- Web Audio API가 바람 소리, 몸짓 중 눈 쓸리는 소리, 덮임 소리, 비상할 때의 차임을 브라우저에서 만듭니다.
- 배경음악은 피아노 캐롤 **Joy to the World**를 반복 재생합니다. 비상 단계에서는 차임이 들리도록 음악 볼륨을 낮춥니다.

## 기술

- [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) (`@mediapipe/tasks-vision` 0.10.18, `pose_landmarker_lite` 모델)
- 런타임(`vendor/`)과 모델(`models/`)을 레포에 포함해 **인터넷 없이** 동작합니다.
- 빌드 과정 없이 로컬 서버에서 `index.html`을 실행합니다.
- 배경음악 파일은 `assets/joy-to-the-world-piano.ogg`에 포함되어 오프라인에서도 재생됩니다.

## 실행

카메라를 쓰려면 `file://`이 아니라 로컬 서버나 HTTPS에서 열어야 합니다.

```bash
cd snow-angel
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```

### 전시장 무인 운영 (Chrome 키오스크)

```bash
chrome --kiosk --autoplay-policy=no-user-gesture-required --use-fake-ui-for-media-stream http://localhost:8000
```

- `--autoplay-policy=...`: 클릭 없이도 소리(바람, 차임)가 나게 합니다.
- `--use-fake-ui-for-media-stream`: 카메라 권한 팝업을 자동으로 허용합니다.

### 운영자 키

| 키 | 기능 |
| --- | --- |
| `D` | 디버그(카메라 미리보기, 관절 점, 진행도, FPS) |
| `F` | 전체화면 |
| `R` | 처음으로 초기화 |
| `C` | 카메라 전환(선택한 카메라는 기억됨) |
| `M` | 소리 끄기/켜기 |

## 설치 메모 (노트북 + TV + TV 위 웹캠)

**연결**
- 노트북을 HDMI로 TV에 연결하고 `Win + P` → **두 번째 화면만**으로 설정하세요. 이렇게 하면 키오스크 창이 TV에 바로 뜨고 노트북 화면은 꺼집니다.
- 노트북 덮개를 닫아도 꺼지지 않게: 제어판 → 전원 옵션 → "덮개를 닫으면" → **아무 것도 안 함**.
- 노트북은 충전기를 꽂은 상태로 운영하세요(배터리 모드에서는 GPU가 느려져 인식이 끊길 수 있음).
- 전시 중에는 화면이 꺼지지 않게 앱이 직접 막아 줍니다(Wake Lock). 그래도 Windows 절전/화면 끄기는 **안 함**으로 두는 걸 권장합니다.

**카메라**
- 앱이 노트북 내장 카메라 대신 외장 웹캠을 자동으로 고릅니다. 시작할 때 화면 아래에 선택된 카메라 이름이 잠깐 표시됩니다.
- 다른 카메라가 잡혔다면 `C`로 바꾸세요. 한 번 고른 카메라는 다음 실행 때도 그대로 쓰입니다.
- 카메라가 분리되거나 영상이 멈추면 화면에 상태를 표시하고 자동으로 다시 연결을 시도합니다.
- 웹캠은 TV 위 가운데에 두고, 관객의 머리부터 무릎(가능하면 발목)까지 화면에 들어오게 살짝 아래로 기울이세요. `D`를 누르면 카메라 화면을 보면서 맞출 수 있습니다. 발목이 안 보이면 무릎으로 다리를 계산합니다.
- 3 × 3m 부스에서는 관객이 TV에서 약 2~2.5m 떨어져야 전신이 잡힙니다. 화각이 넓은(90° 이상) 웹캠이 유리합니다.
- 바닥 지정 위치 2곳은 카메라 화면의 왼쪽과 오른쪽 절반에 하나씩 오도록 표시합니다.
- 3m 부스의 실제 거리값은 카메라만으로 정확히 잴 수 없으므로, 작은 인물 제외 기준은 설치된 웹캠 화각에서 현장 확인이 필요합니다.
