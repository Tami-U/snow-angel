스노우 엔젤 · 현장 운영 안내
================================

■ 켜기 / 끄기
  전시 시작.exe  → 더블클릭하면 크롬이 전체화면으로 전시를 띄웁니다.
  끄기          → 전시 화면에서 ESC 를 두 번 누르세요. (한 번은 안내만 뜸)
  전시 종료.exe  → 더블클릭해도 꺼집니다. (개인적으로 쓰던 크롬 창은 그대로)

  · 인터넷이 없어도 동작합니다. (전시 파일을 이 폴더 바깥 snow-angel 폴더에서 바로 읽음)
  · 카메라 권한 팝업 없이 바로 시작되고, 클릭 없이도 소리가 납니다.
  · 이미 켜져 있을 때 '전시 시작'을 다시 누르면 깨끗하게 새로 켜집니다.

■ 현장 키보드
  R  처음 화면으로 리셋 (화면이 멈추거나 이상할 때 먼저 눌러 보세요)
  C  카메라 바꾸기 (노트북 내장 카메라가 잡혔을 때)
  M  소리 끄기 / 켜기
  I  체험자 집계 보기 (오늘·누적·최근 7일)  →  열린 상태에서 S 를 누르면 엑셀(CSV)로 저장(다운로드 폴더)
  D  점검 화면 (카메라 영상, 인식 점, fps)
  ESC 두 번  전시 끄기 ('전시 종료'와 같음)

■ 알아 두면 좋은 것
  · 아무도 없으면 화면 가운데에서 천사 그리는 시범이 반복됩니다. 사람이 서면 바로 체험이 시작됩니다.
  · 혼자 오면 어디에 서도 인식되고, 천사는 화면 가운데에 그려집니다.
  · 하루 종일 켜 두면 3시간마다 아무도 없을 때 화면이 한 번 자동으로 새로고침됩니다. (정상 동작)
  · 집계는 숫자만 이 노트북에 저장되며 영상·사진은 저장하지 않습니다.
  · 현장에 "카메라 영상은 저장되지 않습니다" 안내판을 함께 두는 것을 권장합니다.

■ 문제가 생기면
  1) R 을 누른다
  2) 안 되면 '전시 종료' → '전시 시작'
  3) 카메라 화면이 안 나오면 USB 웹캠을 다시 꽂는다 (자동으로 다시 연결됨)

■ 처음 설치할 때
  · 노트북을 TV에 HDMI로 연결하고 Win + P → "두 번째 화면만"
  · 전원 옵션: 덮개를 닫으면 "아무 것도 안 함", 절전/화면 끄기 "안 함", 충전기 연결
  · Google Chrome 설치 필요 (없으면 Microsoft Edge로 실행)
  · 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 → "추가 정보" → "실행"
    (인터넷에서 받은 파일이라 한 번 뜨는 확인 창입니다)
